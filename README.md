# Portafolio | Christian Serrano — Ingeniero en Ciberseguridad 🛡️

Sitio web de portafolio profesional, con presentación personal, habilidades y una selección de proyectos prácticos de ciberseguridad desarrollados con Python y Flask.

🔗 **Sitio en vivo**: [christianciber.github.io/cybersecurity-portfolio](https://christianciber.github.io/cybersecurity-portfolio/)

## 📋 Contenido del sitio

- **Sobre mí**: presentación profesional y objetivos de carrera.
- **Habilidades**: áreas de especialización (ciberseguridad, redes, programación).
- **Proyectos**: demos funcionales en vivo, con enlace al código fuente de cada uno.
- **Contacto**: correo, WhatsApp, LinkedIn y GitHub.

## 🧩 Proyectos incluidos

| Proyecto | Descripción | Demo | Código |
|---|---|---|---|
| **Port Scanner Pro** | Escáner de puertos TCP con detección de servicios | [Demo](https://port-scanner-pro.onrender.com) | [Repo](https://github.com/ChristianCiber/port-scanner-pro) |
| **Password Strength Checker** | Evaluador de contraseñas con verificación de filtraciones (HIBP) | [Demo](https://password-strength-checker-bka7.onrender.com) | [Repo](https://github.com/ChristianCiber/password-strength-checker) |
| **File Encryptor AES-256** | Cifrado/descifrado de archivos con AES-256-GCM | [Demo](https://file-encryptor-p1dm.onrender.com) | [Repo](https://github.com/ChristianCiber/file-encryptor) |

> Nota: las demos están alojadas en el plan gratuito de Render, por lo que pueden tardar unos segundos en cargar tras un período de inactividad.

## 🛠️ Tecnologías usadas en el sitio

- HTML5, CSS3, JavaScript (vanilla)
- Diseño responsive (adaptado a móvil y escritorio)
- Publicado con GitHub Pages

## 🚀 Cómo correrlo localmente

Este sitio es completamente estático, no requiere backend ni instalación de dependencias:

```bash
git clone https://github.com/ChristianCiber/cybersecurity-portfolio.git
cd cybersecurity-portfolio
```

Abre `index.html` directamente en tu navegador, o usa una extensión tipo "Live Server" en VS Code para verlo con recarga automática.
